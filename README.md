# NanoGo 教学服务端（免费下载）

给围棋老师、围棋班和学校用的教学服务端。和 [NanoGo 围棋客户端](https://github.com/netbula/NanoGo) 配合：老师和学生用 NanoGo 登录，就能上课、留作业、下指导棋。

- **免费下载使用**，不开源。本仓库只放编译好的程序和说明，没有源码。
- 单个文件，Windows、Linux、macOS 都能用，不用装数据库，几分钟就能架好。
- 客户端在这里：**[NanoGo 围棋](https://github.com/netbula/NanoGo)**。它是免费开源的复盘、对弈、死活题软件，棋力来自 KataGo；不登录也能单机使用。

## 能做什么

**账号和班级**
- 学生、老师、管理员三种角色，账号由管理员开，不能自己注册。
- 管理员可以分班、给学生换班、记段位、停用账号、重置密码。
- 未成年学生开账号时，必须确认已取得监护人同意。
- 重要操作都记进操作日志。

**云棋谱**
- 棋谱存在服务器上，可以一次上传多个 SGF，也可以改名。
- 老师能看自己班学生的棋谱，管理员能看所有人的。

**作业**
- 三种作业：做死活题、复盘指定棋谱、和 AI 下几盘（可以指定 AI 段位）。
- 题目和棋谱可以浏览挑选，带棋盘预览。
- 学生做完提交，老师批改、打分、写评语，学生可以重交。

**对局室**
- 指导棋：老师和学生在线对下，可以让 2～9 子，可以开放给全班观摩。
- 老师可以同时下好几盘指导棋：轮到老师走的那盘会提醒，点一下就切过去。
- 班级大课：老师在棋盘上摆棋讲解，全班实时看到；老师可以把摆棋权交给某个学生。
- 比赛：两个学生对下，老师当裁判，可以悔棋、判输赢。
- 规则可选：中国、中国 2027 新规则、日本、韩国、应氏、AGA、新西兰、Tromp-Taylor。
- 可以计时，用日本式读秒，超时自动判负。比赛默认计时。
- 对局室里可以聊天。
- 下完的棋谱自动存进双方和老师的云棋谱，双方名字、段位、日期、结果都自动写好。

**防作弊**
- 上课和比赛时，学生不能用 NanoGo 的 AI。
- NanoGo 还会检查学生电脑上有没有运行其他围棋 AI（KataGo、Leela Zero、KaTrain、Lizzie 等），发现了就提醒老师，并记进棋谱。
- 只能查同一台电脑。学生用别的设备看 AI，查不到。

**学费和课时**
- 只记账，不经手钱：管理员记缴费、退费、调整课时；老师给自己班的学生记上课。
- 每个学生的剩余课时、累计缴费、最近上课一目了然，课时快用完的标红，提醒续费。
- 结束大课或指导棋时，可以顺手给在场的学生每人记 1 节课；同一节课不会重复扣。
- 记错了可以作废，所有记录都留在操作日志里；可以导出表格。
- 老师看不到金额；学生只能看自己的课时和明细。


## 怎么架

### 在自己电脑上试用（Windows）

解压后，在那个文件夹里打开命令行：

```bat
nanogo-server.exe -init-admin admin
nanogo-server.exe
```

- 第一行新建管理员 `admin`，并打印一个随机密码，登录后请马上改掉。
- 数据存在同一个文件夹的 `nanogo.db` 里。
- 打开 NanoGo，点工具栏右侧的“登录”，服务器填 `http://127.0.0.1:8080`。

### 给局域网里的学生用

用 `nanogo-server.exe -addr 0.0.0.0:8080` 启动，学生的服务器地址填 `http://这台电脑的局域网IP:8080`。Windows 防火墙第一次询问时，允许“专用网络”。

### 放到云服务器上对外服务

- 用 Linux 版。
- 前面加一个 HTTPS 反向代理（Caddy 或 Nginx），学生的服务器地址填你的域名。
- 人多时数据库可以换成 PostgreSQL：`-db postgres://用户:密码@主机/库名`。
- 服务器在中国大陆、又用域名对外服务的，要先做 ICP 备案。
- 每天备份数据库文件（SQLite）或做 `pg_dump`（PostgreSQL）。

### 参数

| 参数 | 说明 |
| --- | --- |
| `-addr` | 监听地址，默认 `127.0.0.1:8080`；环境变量 `NANOGO_ADDR` |
| `-db` | 数据库，默认 `sqlite:nanogo.db`，也可以 `postgres://...`；环境变量 `NANOGO_DB` |
| `-init-admin 名字` | 新建一个管理员（随机密码打印出来）后退出 |
| `-tls-cert` / `-tls-key` | 直接用 HTTPS（一般交给反向代理） |
